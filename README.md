# Лабораторная работа 1 — проекции и аффинные преобразования
# Объёмная каркасная буква «А»

Зависимости: только стандартная библиотека Python 3 (tkinter, math).

## Запуск

Нужен Python с модулем `tkinter` (системный Python на macOS обычно подходит; у Homebrew `python3` Tk часто не собран).

```bash
/usr/bin/python3 main.py
# или
/usr/local/bin/python3 main.py
```

## Что реализовано

- Каркасная 3D-модель буквы «А» (арка с вырезом + перекладина)
- Элементарные аффинные преобразования: перенос, поворот, масштаб (матрицы 4×4 вручную)
- Перспективная и ортогональная проекции
- Управление мышью и клавиатурой
- Динамическое преобразование (анимация): вращение вокруг Z и пульсация масштаба

## Управление

| Действие | Клавиши / мышь |
|----------|----------------|
| Вращение | ЛКМ + движение; R/F, T/G, Y/H |
| Перенос | WASD / стрелки; Q/E (глубина) |
| Масштаб | колесо мыши; +/- |
| Анимация | Пробел |
| Проекция | 1 — ортогональная, 2 — перспективная |
| Сброс | 0 |
| Выход | Esc |
